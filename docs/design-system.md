## サービス3本柱（HP・名刺・パワポ統一済み）

| # | サービス | 内容 |
|---|----------|------|
| 1 | **freee × AI自動化**（メイン） | freee API × Claude連携による経理・労務・請求書処理の自動化 |
| 2 | **Claude活用コンサル** | 社内AI組み込みの戦略・プロンプト設計・ロードマップ策定 |
| 3 | **DX伴走支援** | DX現状診断から実行まで伴走（DXという言葉は必ず含める） |

**Why この3本柱か：** freee × Claude の掛け合わせが具体的で差別化になる。「DXコンサル」「業務自動化」など抽象表現より具体性が高い。

# docs/ — 設計知識・学びの集約

このフォルダは「**あとで読めば再現できる**」をコンセプトに、ブランド成果物（HP・名刺・パワポ）に関する設計判断・ベストプラクティス・落とし穴を集約する場所。

| [design-system.md](design-system.md) | 配色・フォント・サービス3本柱・ロゴ運用ルール |

## 書く方針

- **「将来同じ作業をするとき、これだけ読めば再現できる」レベルの詳細さ**
- 出典URLを必ず明記（後で根拠を辿れるように）
- 落とし穴・やってはいけないことを明示
- Aisunia固有の判断は「なぜこの選択か」を残す

## いつ追加するか

- 新しい成果物（チラシ・SNSヘッダー・スライド等）の作成方針が固まったとき
- 一般論と異なる固有の判断をしたとき
- 同じ間違いを繰り返さんため、トラブル対応の記録を残したいとき
